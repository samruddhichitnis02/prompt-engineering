# Assignment 1: Prompt Engineering

This repository contains code based experiments with six prompt engineering
techniques using LangChain and a local Ollama language model.

## Techniques Used

- Zero Shot Prompting
- Few Shot Prompting
- Chain of Thought Prompting
- Zero Shot Chain of Thought Prompting
- Meta Prompting
- Tree of Thoughts Prompting

## Contents

The Jupyter Notebook contains two examples for each technique. It also
includes the model outputs, findings, and an overall comparison of the
techniques.

## Model and Tools

- Python
- Jupyter Notebook
- LangChain
- Ollama
- Llama 3.2
